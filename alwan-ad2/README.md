# إعلان «مطبعة ألوان» — النسخة الثانية (45 ثانية، 9:16)

- `alwan_ad2_4k.mp4` — 2160×3840، 30fps، 45.6 ثانية، صوت AAC ستيريو (−14 LUFS).
- `alwan_ad2_1080p.mp4` — 1080×1920 للرفع السريع.

المشاهد: فكرة ← تصاميم رمادية ← قطرة حبر وماكينة طباعة ← وصولات وفواتير وقرطاسية وماكينة قص
← الأختام ← واجهة محل بحروف ولافتات ضوئية ← عرض المنتجات والخدمات الإضافية ← شخصية ترفع يدها وتكوين الشعار
← خريطة العراق/بيجي/عمارة وطبان ← الشاشة الختامية.

المصادر: `ad.html` (محرك الرسوم، `render(t)`)، `render.mjs` (تصيير الإطارات)، `audio.py` (موسيقى ومؤثرات ومكساج)، `vo/` (التعليق الصوتي).
