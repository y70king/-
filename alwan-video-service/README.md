# إعلان «مطبعة ألوان» — خدمة الفيديوهات الإعلانية والترويج (9:16)

- `alwan_video_service_4k.mp4` — 2160×3840، 30fps، 124 ثانية، تعليق صوتي عربي فصيح طوال الإعلان، AAC ستيريو (−14 LUFS).
- `alwan_video_service_1080p.mp4` — 1080×1920.

عشرة مشاهد يقودها التعليق الصوتي: هل يصل إعلانك؟ ← الحل (مطبعة ألوان) ← لأي مشروع ← من الفكرة إلى الإعلان
← أسعار مناسبة ← الترويج ← لماذا إعلان احترافي (جذب — وضوح — تذكّر) ← مدينة المشاريع ← التواصل والموقع ← الخاتمة.

توقيت النصوص على الشاشة مأخوذ من توقيت كلمات التعليق الصوتي (`vo/*.json`) ومثبّت في `CUE` داخل `ad.html`.
المصادر: `ad.html` (المشاهد)، `render.mjs` (تصيير الإطارات)، `audio.py` (موسيقى خلفية منخفضة ومؤثرات ومكساج)، `vo/` (التعليق الصوتي).
لاستبدال التعليق بصوت معلّق بشري: ضع ملفات `v1.wav`…`v11.wav` الجديدة في `vo/`، وعدّل أوقات `VO` و`CUE` إن تغيّرت الأطوال، ثم أعد تشغيل `audio.py` والترميز.
