# صانع الجدول المدرسي — نسخة أندرويد

تطبيق عربي بالكامل (من اليمين لليسار) يصنع جدول الدروس الأسبوعي لكل صفوف وشعب المدرسة تلقائياً،
بشرط لا يُكسر: **لا يوضع المدرس في صفين أو شعبتين بنفس الحصة**.

## التثبيت

ملف التثبيت الجاهز: [`release/SchoolTimetable.apk`](release/SchoolTimetable.apk)

1. انقل الملف إلى الهاتف وافتحه.
2. اسمح بـ«التثبيت من مصادر غير معروفة» عند السؤال.
3. يعمل على أندرويد 7.0 فما فوق، ولا يحتاج إنترنت.

كما يبني GitHub Actions ملف APK جديداً تلقائياً عند أي تعديل في هذا المجلد
(Actions ← Build School Timetable APK ← Artifacts).

## الخطوات

| الخطوة | المحتوى |
|---|---|
| ١. الأيام والحصص | أيام الدوام وعدد حصص كل يوم (1–12)، توحيد العدد، والملخص (S = مجموع الحصص الأسبوعية) |
| ٢. المدرسون | إضافة عدة مدرسين دفعة واحدة، الاختصاص، النصاب (أحمر إذا تجاوز S)، تعديل/حذف، وإسناد مادة لعدة صفوف |
| ٣. الصفوف والمواد | إضافة صف بعدة شعب (أ، ب، ج…)، مختار المواد مع المدرس وعدد الحصص (0 = تلقائي)، الترتيب، نسخ المواد |
| ٤. الجدول | التحليل، الإنشاء في الخلفية مع زر إيقاف، العرض (كامل / صف / مدرس)، التبديل اليدوي باللمس، التصدير |

- **الاستيراد من ملف:** زر «📥 استيراد من ملف» في خطوتي المدرسين والصفوف يقرأ ملفات Excel (xlsx) و Word (docx) و PDF و CSV،
  ويتعرف تلقائياً على أعمدة «اسم المدرس، الاختصاص، الصف، الشعبة، عدد الشعب» مع معاينة قابلة للتعديل قبل الإضافة.
  يوجد أيضاً «نموذج Excel جاهز» للتعبئة. (نص PDF العربي قد يحتوي أخطاء في بعض الحروف، لذلك يُفضَّل Excel أو Word.)
- **الجدول الكامل** بالشكل الورقي المعتاد: الأيام والحصص أسطر، ولكل صف عمودان «المادة | المدرس» بلون مميز
  (مع خيار العرض القديم: الصفوف أسطر).
- **الحفظ تلقائي** بعد كل تغيير. من القائمة ☰: مشروع جديد، فتح ملف، حفظ نسخة (JSON).
- ملف JSON بنفس صيغة نسخة الحاسوب، فيمكن نقل البيانات بين الحاسوب والهاتف.
- الملفات المصدّرة (Excel و Word) تُحفظ في `Download/SchoolTimetable` مع زر مشاركة وفتح.

## الخوارزمية

1. **توزيع الحصص التلقائية:** المواد ذات العدد المحدد تأخذ عددها، والتلقائية تقتسم الباقي حصة حصة
   وبالتناوب بين الصفوف، دون أن يتجاوز نصاب المدرس S.
2. **المرحلة 1 — جدول مضمون بلا تعارض:** تلوين حواف الرسم الثنائي (صف ↔ مدرس) بـ S لون مع قلب
   المسارات المتناوبة. حسب مبرهنة كونيغ يوجد الحل دائماً ما دام كل صف وكل مدرس ≤ S.
3. **المرحلة 2 — تحسين الجودة (محاكاة التلدين):** التكلفة = 100×التعارضات + 6×تكرار المادة في اليوم
   فوق ⌈حصصها÷الأيام⌉ + 2×الفراغات قبل آخر درس في اليوم. الحركات: تبديل خانتين في نفس الصف،
   وحركة «سلسلة كمبه» التي تبدّل الخانتين في كل الصفوف المترابطة عبر المدرسين دون أي تعارض
   (تسمح بالتحسين حتى عندما يكون المدرسون ممتلئين).

## البنية

```
school_timetable/
├── app/src/main/java/.../MainActivity.java   ← غلاف أندرويد (WebView + جسر الحفظ والمشاركة)
└── app/src/main/assets/www/
    ├── index.html, css/style.css
    └── js/
        ├── model.js    ← البيانات، التوزيع التلقائي، التحليل والاقتراحات
        ├── engine.js   ← تلوين الحواف + محاكاة التلدين
        ├── worker.js   ← تشغيل البحث في الخلفية
        ├── export.js   ← Excel و Word (RTL، A3/A4 بالعرض)
        ├── import.js   ← استيراد المدرسين والصفوف من Excel / Word / PDF / CSV
        ├── zip.js      ← كاتب ZIP
        └── app.js      ← الواجهة
    └── lib/            ← pdf.js (Apache 2.0) و fflate (MIT) لقراءة الملفات دون إنترنت
```

يمكن تجربة الواجهة على الحاسوب أيضاً: شغّل خادماً محلياً داخل `app/src/main/assets/www`
(مثلاً `python3 -m http.server`) وافتح `index.html` في المتصفح.

## البناء

```
cd school_timetable
./gradlew assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```
يحتاج JDK 17+ و Android SDK (compileSdk 34).
