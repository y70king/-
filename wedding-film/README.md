# 🌹 «وردة غيّرت عمرنا» — حزمة إنتاج فيلم الزفاف

فيلم أنميشن رومانسي، 3 دقائق، 4K (3840×2160)، 24 إطار/ثانية، 16:9، تعليق صوتي باللهجة العراقية.

هذا المجلد يحوّل السيناريو إلى خطة إنتاج جاهزة: 44 لقطة مؤقّتة بالثانية، برومبت إنجليزي جاهز
لكل لقطة لأدوات توليد الفيديو بالذكاء الاصطناعي، نص التعليق الصوتي بتوقيته، العناوين العربية
مصممة ومؤقتة، وأداة تجمع كل شيء في الفيلم النهائي بأمر واحد.

> الحزمة لا تحتوي لقطات الأنمي نفسها، فهي تُولَّد بأداة فيديو (Kling / Veo / Sora / Runway / Hailuo)
> أو يرسمها فنان. كل لقطة تجهز تضعها في `clips/` فتأخذ مكانها تلقائياً في الفيلم.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `shots.json` | **المصدر الأساسي**: الأسلوب، البرومبت السلبي، وصف الشخصيات، ملابس كل مرحلة، و44 لقطة بمددها |
| `prompts.md` | البرومبت الكامل لكل لقطة (مولَّد من `shots.json`)، للنسخ مباشرة إلى أداة الفيديو |
| `voiceover.srt` | نص التعليق الصوتي بالتوقيت الدقيق، للمعلّق أو لأداة تحويل النص إلى صوت |
| `titles.ass` | العبارات والتواريخ على الشاشة بخط Amiri وتأثيرات ظهور واختفاء ناعمة |
| `build.py` | أداة التجميع: تحقق، برومبتات، معاينة، فيلم نهائي |
| `fonts/` | خط Amiri العربي (رخصة OFL مرفقة) |

## خطوات الإنتاج

### ١. صور مرجعية ثابتة للشخصيات (أهم خطوة لثبات الملامح)
قبل أي لقطة، ولّد بأداة صور (Midjourney / Flux / ChatGPT) **صفحة شخصية** لكل من العروس ومحمد
والصديقة: وجه أمامي وجانبي وجسم كامل، بكل مرحلة ملابس (`uni`، `baghdad`، `tikrit`، `engagement`،
`wedding`). استخدم وصف `characters` و`outfits` من `shots.json` مع جملة `style`.
إذا تريدون الشخصيات تشبهكم، أرفقوا صوركم الحقيقية كمرجع بأسلوب أنمي.

بعدها ولّد كل لقطة بطريقة **image-to-video**: صورة أولى للقطة مرسومة من الصفحة المرجعية، ثم
البرومبت من `prompts.md`. هذه الطريقة تحافظ على الوجوه والملابس أكثر بكثير من النص وحده.

### ٢. توليد اللقطات
- لكل لقطة في `prompts.md`: الصق **Style + Prompt**، وضع **Negative** في البرومبت السلبي.
- اضبط الأداة على 16:9 و24fps وأعلى دقة متوفرة. ولّد 2–3 نسخ واختر أفضلها (راجع الأيدي والوجوه).
- احفظ الملف باسم رقم اللقطة: `clips/06d.mp4`. يمكن أيضاً وضع صورة ثابتة `clips/06d.png`
  فتتحرك بحركة كاميرا بطيئة.
- إذا كانت اللقطة أطول من المطلوب تُقصّ، وإذا كانت أقصر يُجمَّد آخر إطار.
- **لا تجعل الأداة تكتب نصاً عربياً داخل الفيديو.** كل العناوين تضاف من `titles.ass` بخط سليم،
  والبرومبتات تترك مساحة فارغة مكانها.
- إذا كانت الأداة تخرج 1080p، فالأفضل رفع الدقة بأداة متخصصة (مثل Topaz Video AI) قبل التجميع.
  `build.py` يكبّر الصورة لـ 4K لكنه لا يضيف تفاصيل.

### ٣. التعليق الصوتي
السرد بصوت العروس (بصيغة المتكلم)، فأجمل خيار أن تسجّله هي بصوتها، أو صوت عراقي دافئ، أو
أداة TTS تدعم اللهجة العراقية. `voiceover.srt` فيه كل جملة ووقتها.
سجّل ملفاً واحداً بطول 3 دقائق يبدأ من 00:00 وتقع كل جملة في وقتها، واحفظه باسم
`audio/voiceover.wav`. وقفات مقترحة: بعد «بس بكيت.» وقبل «وكأن قلبي أخيراً لگه مكانه.»

### ٤. الموسيقى (`audio/music.wav`)
| الوقت | الإحساس |
|---|---|
| 00:00–00:20 | بيانو ناعم جداً، نوتات متفرقة |
| 00:20–01:20 | بيانو دافئ ومرح خفيف |
| 01:20–01:40 | بيانو أكثر حزناً بلون أزرق |
| 01:40–02:00 | كمان يدخل وتصاعد أوركسترالي تدريجي |
| ≈02:00 | توقف قصير جداً عند تلاقي النظرات |
| 02:05–02:35 | عودة دافئة مليئة بالأمل |
| 02:35–02:50 | الذروة العاطفية (الخطوبة) |
| 02:50–03:00 | هدوء وختام، آخر نوتة تمتد للنهاية |

استخدم موسيقى مؤلفة لكم أو مرخّصة للاستخدام. عند التجميع يخفض `build.py` الموسيقى تلقائياً
تحت التعليق الصوتي ويخفتها في آخر 3 ثوانٍ. الأصوات المحيطية (شارع، جامعة، ماء دجلة) تُدمج مع
الموسيقى بمستوى خافت.

### ٥. التجميع
يحتاج `python3` و`ffmpeg` (مع libass):

```bash
python3 build.py check      # تحقق من التوقيتات
python3 build.py animatic   # معاينة 720p بالتعليق مكتوباً، والبطاقات مكان اللقطات الناقصة
python3 build.py final      # الفيلم النهائي: wardah-final-4k.mp4 (4K / 24fps / H.264 + AAC)
```

`animatic` مفيدة في كل مرحلة: تشوف فيها الإيقاع، واللقطات الجاهزة تظهر مكانها، والناقصة تظهر
كبطاقة ملونة عليها رقمها ووصفها.

### ٦. الأسماء وموعد الزفاف
آخر سطر في `titles.ass` جاهز لهذا الغرض: غيّر `Comment:` إلى `Dialogue:` واكتب الأسماء أو الموعد.
يظهر أسفل الشاشة في آخر ثانيتين ولا يغطي العبارة الختامية.

## تعديل اللقطات
عدّل `shots.json` (المدة، الوصف، البرومبت، الملابس) ثم:
```bash
python3 build.py check && python3 build.py prompts
```
`{BRIDE}` و`{MOHAMMED}` و`{FRIEND}` داخل البرومبت تُستبدل تلقائياً بالوصف الكامل وملابس المرحلة،
فلا تضطر لتكرار الوصف بكل لقطة ويبقى ثابتاً.
يجب أن يبقى مجموع المدد 180 ثانية، وكل مدة تساوي عدداً صحيحاً من الإطارات (مضاعفات 1/24 ثانية).
