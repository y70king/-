# 📘 مُخطِّط المعلم

تطبيق ويب يساعد المدرس على إنشاء **خطة يومية / أسبوعية / شهرية / سنوية** من كتاب المادة بصيغة PDF:

1. **بيانات المدرس**: اسم المدرس، المادة، الصف، المدرسة، العام الدراسي (تُحفظ في المتصفح وتظهر في رأس الخطة المطبوعة).
2. **رفع الكتاب** (PDF): يحسب التطبيق عدد الصفحات تلقائياً.
3. **إعدادات الخطة**: عدد الصفحات لكل يوم، من صفحة إلى صفحة، تاريخ البداية، أيام الدراسة في الأسبوع، وأيام العطل.
4. **الشرح والتلخيص**: لكل درس يومي يحلل التطبيق صفحاته ويكتب: عنوان الدرس، الأهداف، شرحاً مبسطاً، أهم النقاط، المصطلحات، أنشطة مقترحة، وأسئلة تقويم.
5. **عرض الخطة**: يومية (درس بدرس) أو أسبوعية أو شهرية أو سنوية (ملخص الشهور)، مع **طباعة / حفظ PDF** و**تصدير Excel**.

## التشغيل

```bash
cd teacher_planner
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # اختياري: لتفعيل الشرح الذكي
python app.py
```

ثم افتح: <http://localhost:5000>

## وضعا الشرح

| الوضع | متى | الجودة |
|---|---|---|
| ✨ **الشرح الذكي** (Claude) | عند ضبط `ANTHROPIC_API_KEY` | يقرأ صفحات الـ PDF مباشرة (حتى الكتب المصورة/الممسوحة ضوئياً) ويكتب شرحاً وأهدافاً وأسئلة كاملة |
| تلخيص محلي | بدون مفتاح، أو عند فشل الاتصال | يستخرج أهم الجمل والمصطلحات من نص الكتاب فقط (لا يعمل مع الكتب المصورة) |

النموذج الافتراضي `claude-opus-5-5`، ويمكن تغييره عبر متغير البيئة `CLAUDE_MODEL`.

## الملفات

- `app.py` — خادم Flask وواجهات الـ API (`/api/upload`, `/api/plan`, `/api/summarize`).
- `planner.py` — توزيع الصفحات على أيام الدراسة + التلخيص المحلي.
- `pdftext.py` — استخراج نص عربي سليم من PDF (إصلاح ترتيب الكلمات المعكوس و"لا").
- `ai.py` — الشرح باستخدام Claude.
- `templates/index.html`, `static/` — الواجهة (عربية RTL، تعمل على الجوال).

> الخطة والشروح تُحفظ في متصفح المدرس (localStorage)، وملفات الكتب تُحفظ في مجلد `uploads/`.
