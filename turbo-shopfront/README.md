# واجهة محل «تيربو للتوصيل السريع»

- `shopfront_night.*` — منظور ليلي (الحروف والشعار والإضاءة LED مضاءة).
- `shopfront_day.*` — منظور نهاري.
- `shopfront_spec.*` — مخطط تنفيذ مقترح: مقاسات تقريبية لواجهة بعرض ≈ 6 م + جدول المواد والألوان.

PNG بدقة 3840×2160، وJPG للمشاركة. المقاسات مقترحة وتُعدَّل حسب القياس الفعلي للمحل.
إعادة التوليد: `node render.mjs` (التصميم في `shopfront.html` ويعيد استخدام عناصر هوية تيربو).
