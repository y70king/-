# من أول وردة إلى خاتم العمر ❤️

فيلم موشن جرافيك رومانسي (16:9، بدقة 4K) يحكي القصة من 14 فبراير 2023 إلى الخطوبة في 5 ديسمبر 2025، مع تعليق صوتي بالعربية الفصحى وموسيقى بيانو وكمان.

كل شيء في الفيلم مرسوم بالكود (Canvas)، لذلك يمكن تعديل أي نص أو توقيت أو لون ثم إعادة إخراجه.

## التشغيل

| الطريقة | الأمر |
|---|---|
| مشاهدة فورية في المتصفح (مع الصوت) | افتح `index.html` (المسافة = تشغيل/إيقاف، `f` = ملء الشاشة) |
| إضافة اسمي العروسين في اللقطة الأخيرة | `index.html?names=الاسم ❤ الاسم` |
| البدء من ثانية معينة | `index.html?t=75` |

## إعادة الإخراج

```bash
pip install edge-tts numpy
python3 tools/tts.py              # التعليق الصوتي من narration.json (صوت ar-SA-HamedNeural)
python3 tools/build_timeline.py   # توقيت المشاهد يُبنى من مدة التعليق الصوتي
python3 tools/audio.py            # الموسيقى + المؤثرات + المزج
node tools/render.js --scale 2    # فيديو 4K في out/film-4k.mp4  (--scale 1 لنسخة 1080p)
```

لتغيير النص: عدّل `narration.json` ثم أعد الأوامر بالترتيب. التوقيتات تتكيّف تلقائيًا.

## الملفات

- `src/chars.js` — الشخصيات الثلاث (شكل ثابت في كل المشاهد)، الورود، الأيدي والأغراض
- `src/env.js` — الأماكن: سنتر القانون، الممر، الجامعة، الخريطة، جسر الأحرار، تكريت
- `src/scenes.js` — المشاهد العشرة وانتقالاتها
- `src/engine.js` — تركيب المشاهد والانتقالات لأي لحظة زمنية
- `audio/` — التعليق الصوتي والمزج النهائي
