# بوت إشارات الذهب (XAUUSD) — ICT / SMC

بوت يعمل بالكامل على **GitHub Actions** (بدون VPS أو لابتوب) ويرسل إشارات
دخول على الذهب عبر تيليجرام، بالاعتماد على:

- **فريم الساعة (1H)** → تحديد الهيكل العام (Bias) عبر BOS / CHoCH
- **فريم 15 دقيقة** → تأكيد الهيكل + تحديد منطقة الدخول (FVG / Order Block)
- **فريم 5 دقائق** → زناد الدخول (شمعة تأكيد داخل المنطقة)

يحسب تلقائياً: نقطة الدخول، وقف الخسارة، وثلاثة أهداف ربح (TP1/TP2/TP3)
بنسب مخاطرة/عائد 1.5 / 2.5 / 4.0.

---

## ⚠️ أول خطوة — غيّر التوكن فوراً

التوكن اللي أرسلته صار مكشوف. روح لـ **BotFather** على تيليجرام وسوي:
```
/revoke
```
وخذ توكن جديد. لا تحط التوكن الجديد أبداً داخل الكود، فقط كـ Secret (بالخطوة 3).

## خطوات الإعداد (5 دقائق)

### 1. إنشاء ريبو على GitHub
سوي ريبو جديد (يفضّل **Private** حتى لو ما فيه توكنات بالكود، احتياطاً)
وارفع هذي الملفات:
```
gold_signal_bot.py
requirements.txt
.github/workflows/signal_bot.yml
```

### 2. رفع الملفات
من هاتفك تقدر تستخدم تطبيق GitHub أو موقع github.com مباشرة (زر Add file → Upload files).

### 3. إضافة الأسرار (Secrets)
بالريبو: **Settings → Secrets and variables → Actions → New repository secret**

أضف اثنين:
| الاسم | القيمة |
|---|---|
| `TELEGRAM_TOKEN` | التوكن الجديد بعد الـ revoke |
| `TELEGRAM_CHAT_ID` | `806539118` |

### 4. تفعيل الـ Workflow
روح لتبويب **Actions** بالريبو، فعّل الـ workflows إذا طلب منك، وشغّله يدوياً
أول مرة عبر **Run workflow** للتأكد إنه يشتغل صح.

بعدها راح يشتغل تلقائياً كل 5 دقائق ويرسل أي إشارة جديدة على تيليجرام.

## ضبط الحساسية (عدد الإشارات باليوم)

كل الإعدادات بأعلى ملف `gold_signal_bot.py` داخل صنف `Config`:

- `FVG_MIN_SIZE_ATR` (افتراضي 0.15): قلّله عشان مناطق دخول أكثر (إشارات أكثر)،
  كبّره عشان مناطق أدق (إشارات أقل بس أقوى).
- `MAX_ZONE_AGE_BARS` (افتراضي 40): كبّره عشان يقبل مناطق أقدم = فرص أكثر.
- `RR_TARGETS`: نسب الأهداف، عدّلها حسب أسلوبك.
- `ENTRY_INTERVAL`: حالياً `5m`. تقدر تغيّرها لـ `1m` لو تبي دخول أدق
  (بس البيانات التاريخية لفريم الدقيقة محدودة بـ 7 أيام من يفنانس).

كل تشغيل يحسب `signal_id` فريد للإشارة الحالية (بناءً على الاتجاه + وقت
المنطقة + وقت الدخول)، ويقارنه بآخر إشارة محفوظة بملف `state.json`.
إذا نفس الإشارة → ما يرسل مرة ثانية. إذا إشارة جديدة → يرسل ويحدّث الملف
ويرفعه (commit) تلقائياً على الريبو.

## ملاحظة على مصدر البيانات

يستخدم يفنانس (`GC=F` عقود الذهب الآجلة، مع `XAUUSD=X` كبديل). الفرق

# 🧠 مصنع العقول (Neuroevolution) — مجلد `evolution/`

نفس فكرة المقطع: نطوّر آلاف "العقول" (شبكات عصبية صغيرة)، كل عقل يتداول
بألف دولار وهمية، اللي يخسر يموت واللي يربح يتكاثر، ونكرر لآلاف الأجيال.
وبعدين نختبر البطل باختبار القرود قبل ما نصدقه.

## كيف يشتغل

| المرحلة | الملف | وش يسوي |
|---|---|---|
| 1. البيانات | `evolution/data.py` | ينزل سنتين شموع مجانية من Dukascopy (ذهب، فضة، يورو، باوند، بيتكوين، إيثيريوم، S&P500) |
| 2. الحواس | `evolution/features.py` | زخم، تذبذب، RSI، متوسطات، **هيكل السوق (BOS/CHoCH، القمم والقيعان، فجوات FVG)**، الوقت واليوم — كلها نسبية عشان العقل يفهم أي سوق، وهو اللي يقرر وش يهمه منها |
| 3. العقل المحترف | `evolution/brain.py` | شبكة عصبية **بذاكرة**، تقرر بنفسها كل شي: الاتجاه، **حجم الصفقة**، **وقف الخسارة**، **الهدف**، ومتى تطلع قبلهم. ما فيه ولا رقم ثابت — كل عقل يخترع أسلوبه، والامتحان يوصف لك أسلوبه (مدة الصفقة، الوقف/الهدف اللي يحبه، نسبة الربح...) |
| 4. التطور | `evolution/train.py` | 300 عقل بكل جيل، يتداولون فترات عشوائية من أسواق مختلفة مع **إخفاء معلومات + ضجيج** (ضد الحفظ). أفضل 30% يعيشون ويتزاوجون مع طفرات |
| 5. اختبار القرود | `evolution/monkey.py` | كل 25 جيل: أفضل عقل يتداول فترة ما شافها ضد 1000 قرد عشوائي. ما ينحفظ "بطل" إلا إذا تفوق على 95% منهم **وعلى الشراء والاحتفاظ**، **ونجح كمان بنص الأسواق الثانية على الأقل** بنفس الفترة |
| 6. الامتحان النهائي | `evolution/exam.py` | يختبر البطل على آخر شهرين ما شافهم أبداً |
| 7. تداول تجريبي | `evolution/paper_trade.py` | إذا نجح بالامتحان: يتداول ذهب حي بفلوس وهمية كل 5 دقائق ويرسل لك الصفقات على تيليجرام |

تقسيم البيانات زمنياً (العقل ما يشوف المستقبل أبداً):
```
[ ............. تدريب (75%) ............. | تحقق 15% | امتحان نهائي 10% ]
```

## 💵 التحدي: حساب سنت بـ 20$ + 4 صفقات باليوم على الأقل

**التحديث:** حساب 35$ العادي طلع شبه مستحيل (أصغر صفقة 0.01 لوت = أونصة كاملة،
وكل صفقة تخاطر بجزء كبير من الحساب + السبريد ياكل ~3.5% يومياً). صار التدريب على
**حساب سنت بـ 20$** (2000 سنت): 0.01 لوت = 0.01 أونصة، يعني الصفقات أصغر بـ 100 مرة
والعقل يقدر يدير مخاطرته. رافعة بلا حدود وسبريد 20–30 سنت للأونصة.

### الإعدادات القديمة (حساب 35$ عادي)

- كل عقل يبدأ بـ **35$** بحساب مثل الوسيط: لوت الذهب 100 أونصة، أقل شي **0.01 لوت**
  (كل 1$ حركة بالذهب = 1$ ربح/خسارة)، رافعة 1:500، Stop Out إذا الهامش ما كفى، وسبريد بالدخول والخروج.
- العقل يختار **نسبة المخاطرة** (1%–10%) والوقف والهدف، ومنها ينحسب اللوت. إذا الحساب صغير
  والوقف بعيد، مجبور على 0.01 لوت — فلازم يتعلم يحط وقف قريب ويدير مخاطرته.
- لازم يفتح **4 صفقات باليوم على الأقل** (أكثر مسموح). اللي يتداول أقل يتعاقب بالتدريب،
  والبطل والامتحان النهائي لازم يحققونه.
- التمرين على **الذهب بس** (+ نسخة مقلوبة منه). تاريخ الذهب يتوسع لـ 10 سنين عن طريق
  workflow اسمه **Fetch Gold History** (شغّله كم مرة لين يخلص — يكمل من وين وقف).

## التشغيل من الجوال (GitHub Actions)

1. **Actions → Train Brains (Neuroevolution) → Run workflow**
   - `minutes`: مدة التدريب (افتراضي 300 دقيقة = 5 ساعات ≈ آلاف الأجيال)
   - `timeframe`: فريم العقل — **60 (ساعة، الافتراضي)** أو 5 (خمس دقائق). كل فريم له عقوله بمجلد `evolution/models/<الفريم>m/`
   - كل تشغيل **يكمل من آخر جيل** (يحفظ التقدم بـ `evolution/models/`)
   - بالنهاية يرسل لك على تيليجرام نتيجة التدريب + الامتحان النهائي
2. شغّله كم مرة لين يطلع لك بالتيليجرام: **"العقل جاهز للتداول التجريبي"**
3. بعدها بوت الإشارات (كل 5 دقائق) يشغّل العقل تلقائياً على فلوس وهمية،
   ويرسل كل صفقة + ملخص يومي. الحساب محفوظ بـ `evolution/paper_state_60m.json`.
   (على فريم الساعة، تأخير GitHub بالجدولة ما يضر: العقل يعالج كل الشموع اللي فاتته بالترتيب.)

## التشغيل على كمبيوتر / Google Colab (أسرع)

```bash
pip install -r requirements.txt
python -m evolution.data                  # تنزيل/تحديث البيانات
python -m evolution.train --minutes 60    # تدريب ساعة (يكمل من وين وقف)
python -m evolution.exam                  # الامتحان النهائي
python -m evolution.paper_trade           # تداول تجريبي (تشغيل واحد)
```
خيارات: `--fresh` يبدأ من الصفر، `--generations 1000` عدد أجيال محدد.
للتجربة السريعة بدون Dukascopy: `BRAIN_DATA_SOURCE=yahoo` (آخر 60 يوم فقط).

كل الإعدادات (عدد العقول، الطفرة، التكاليف، نسبة إخفاء المعلومات، شرط
اختبار القرود...) بملف `evolution/config.py`.

## ⚠️ مهم تعرفه

- **أغلب العقول راح تفشل بالامتحان النهائي** — وهذا طبيعي وهذا الهدف من الاختبار.
  بأول تجربة طلع عقل ربح +22% على التحقق وتفوق على 97% من القرود، وبالامتحان
  النهائي خسر 4.5%. يعني كان حظ. بالضبط مثل اللي صار بالمقطع.
- **ليش أغلب العقول كانت تفشل:** بيانات التدريب (2024–2026) أغلبها صعود قوي للذهب، فالعقول
  تعلمت "اشتري دايماً"، وبفترة الامتحان الذهب نزل ~16% فخسرت. الحل: التدريب صار كمان على
  **نسخة مقلوبة** من كل سوق (الصعود يصير هبوط)، عشان العقل يتعلم يقرأ السوق بالاتجاهين.
- **ضد الحفظ:** كل جيل يتداول 8 فترات، ضجيج وإخفاء معلومات أكثر، عقوبة على العقل المعقد،
  و"عصور": إذا العقول وقفت تتحسن على بيانات ما شافتها، نبدأ عقول جديدة بدل ما تحفظ أكثر.
- لا تشغّل الامتحان النهائي بعد كل تدريب وتختار "اللي نجح" — كثرة المحاولات
  تخلي حتى الحظ ينجح. النجاح الحقيقي = تداول تجريبي ناجح **لأشهر**.
- **دقائق GitHub Actions:** الريبو الخاص (Private) له 2000 دقيقة مجانية بالشهر.
  تدريب 5 ساعات = 300 دقيقة، وبوت الإشارات كل 5 دقائق لحاله ياكل أكثر من الحد.
  إذا الريبو **عام (Public)** الدقائق مجانية بلا حد (الأسرار تبقى محمية).
- لا تحط فلوس حقيقية على أي عقل قبل ما ينجح بالتداول التجريبي فترة طويلة.
