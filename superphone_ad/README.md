# إعلان موشن جرافيك – مكتب سوبر فون

فيديو إعلاني عمودي (9:16 بدقة 1080×1920، 30 إطارًا/ث، حوالي 23 ثانية) للإعلان عن خدمة ترويج فيديوهات تيك توك
بسعر **٥,٠٠٠ دينار عراقي فقط** مع **ترويج كل يومين**.

**الملف النهائي:** `super_phone_tiktok_ad.mp4`

| المشهد | الوقت | المحتوى |
|---|---|---|
| ١ – لفت الانتباه | 0 – 4.5 ث | خطوط نيون تشكّل إطارًا حول هاتف ثلاثي الأبعاد يدور، أيقونات تفاعل تدور حوله، عنوان «هل تريد ترويج فيديوهاتك على تيك توك؟» |
| ٢ – تقديم الخدمة | 4.5 – 10 ث | شاشة الهاتف تنفتح على بطاقات فيديو، رسوم بيانية متحركة، كتابة ضوئية لـ«سوبر فون» ثم «الآن، خدمة ترويج فيديوهات تيك توك متوفرة لدينا!» |
| ٣ – إبراز السعر | 10 – 16 ث | تجمّع العناصر ثم ومضة ذهبية تكشف «٥,٠٠٠ دينار عراقي فقط» بحركة ثلاثية الأبعاد، ثم «ترويج كل يومين» |
| ٤ – الخاتمة | 16 – 23 ث | الأيقونات تنسحب لتكشف شعار «سوبر فون» والمعلومات النهائية، ثم ومضة ختامية ونغمة نهائية |

## إعادة التوليد

```bash
python3 tts.py ar-SA-HamedNeural +22%   # التعليق الصوتي (edge-tts) ← audio/vo*.mp3، ثم قصّ الصمت إلى audio/vo*.wav
python3 music.py                         # الموسيقى الإلكترونية والمؤثرات ← audio/music.wav
node render.js video_silent.mp4 30       # رسم الإطارات من scene.html عبر Playwright + ffmpeg
./mix.sh                                 # المزج (تخفيض الموسيقى تلقائيًا أثناء الكلام) والدمج ← super_phone_tiktok_ad.mp4
```

- `scene.html` – كل الرسوم والحركة (HTML/CSS 3D + Canvas)، ويمكن فتحه في المتصفح لمعاينة حيّة.
- `node render.js --stills 2,8,13,20 <مجلد>` لاستخراج لقطات ثابتة.
- الخطوط: Cairo و Reem Kufi (Google Fonts، رخصة OFL) محفوظة في `fonts/`.
