# 📘 مُخطِّط المعلم — تطبيق أندرويد

تطبيق يساعد المدرس على إعداد **خطة يومية / أسبوعية / شهرية / سنوية** من كتاب المادة (PDF)، مع شرح كل درس،
وتصدير الخطة بصيغة **PDF** أو **Word** بتنسيق رسمي.

## التثبيت على الهاتف

1. نزّل الملف [`release/teacher-planner.apk`](release/teacher-planner.apk) على هاتفك.
2. افتحه ووافق على "التثبيت من مصادر غير معروفة" إذا طلب الهاتف ذلك.
3. يعمل على أندرويد 7 فما فوق.

## طريقة الاستخدام

1. **بيانات المدرس**: الاسم، المادة، الصف والشعبة، المدرسة، العام الدراسي، والترويسة الرسمية
   (جمهورية العراق / وزارة التربية / المديرية العامة للتربية في ...). تظهر كلها في أعلى الخطة المصدّرة.
2. **الكتاب**: اختر ملف PDF من الهاتف. يُحفظ داخل التطبيق ولا تحتاج رفعه مرة أخرى.
3. **إنشاء خطة**:
   - اختر النوع: يومية / أسبوعية / شهرية / سنوية.
   - حدد **من صفحة** و**إلى صفحة**، مثلاً خطة أسبوعية من صفحة 2 إلى صفحة 10.
   - اختر تاريخ البداية وأيام الدوام (الأحد–الخميس افتراضياً) والعطل.
   - طريقة التوزيع:
     - **تلقائي**: تتوزع الصفحات بالتساوي على أيام الفترة. مثال: أسبوع فيه 5 أيام دوام و 9 صفحات = 2،2،2،2،1.
     - **عدد ثابت**: مثلاً صفحتان كل يوم حتى تنتهي الصفحات.
4. **الشرح**: زر "شرح كل الدروس" يكتب لكل درس: العنوان، الأهداف، الشرح، أهم النقاط، المصطلحات، الأنشطة، وأسئلة التقويم.
5. **التصدير**: زر "تصدير PDF / Word":
   - تصدير المعروض (يوم/أسبوع/شهر) أو الخطة كاملة.
   - اختيار الخط: Simplified Arabic (الرسمي)، Traditional Arabic، أميري، نسخ.
   - إرفاق الشرح الكامل لكل درس (اختياري).
   - الملف: صفحة A4 أفقية، فيها ترويسة رسمية، وجدول (ت، اليوم، التاريخ، الصفحات، عنوان الدرس، الأهداف،
     طرائق التدريس، التقويم، الملاحظات)، وأماكن توقيع المدرس والمشرف والمدير، وأرقام الصفحات.
   - يُحفظ في `المستندات/مخطط المعلم` وتفتح نافذة للمشاركة (واتساب، تلكرام، Drive...).

## الشرح التلقائي (بدون إنترنت وبدون مفتاح)

زر "شرح كل الدروس" يحلل صفحات كل درس داخل الهاتف تلقائياً:

| ماذا يستخرج | كيف |
|---|---|
| عنوان الدرس | من العناوين الكبيرة أو "الدرس ..." |
| التعاريف والمصطلحات | من جمل مثل "الوتر: هو ..." و "تعرف السرعة بأنها ..." |
| **القوانين والمعادلات** | تُقص **كصورة من الكتاب نفسه** فتبقى الكسور والأسس والجذور والرموز مطابقة 100% |
| **الأمثلة المحلولة** | من "مثال ..." حتى نهاية الحل، كصورة من الكتاب |
| أسئلة التقويم | تمارين الكتاب الحقيقية ("تمارين"، "أسئلة الدرس"، "س1:"...) |
| الأهداف والأنشطة | تُكتب تلقائياً حسب المحتوى (تعريف، تطبيق قانون، حل مسائل...) |
| الكتب المصوّرة | تعرّف ضوئي على النص العربي (OCR) داخل الهاتف |

- اضغط على أي صورة لتكبيرها.
- **اختياري**: إذا أضفت مفتاح Claude API من ⚙️ الإعدادات، يكتب شرحاً أوسع بأسلوب المعلم، وتبقى صور القوانين والأمثلة من الكتاب.

## المظهر

زر 🌙 / ☀️ أعلى الشاشة للتبديل بين الوضع الداكن والفاتح، أو "تلقائي" من الإعدادات حسب إعداد الهاتف.
الملفات المصدّرة (PDF و Word) تبقى بخلفية بيضاء للطباعة.

## للمطورين

```bash
cd teacher_planner
npm install
npm run dev          # تشغيل في المتصفح
npm test             # اختبارات توزيع الصفحات وترتيب النص العربي
npm run android      # بناء APK (يحتاج Android SDK و JDK 21)
```

- `src/schedule.js` — توزيع الصفحات على الأيام.
- `src/pdfbook.js` — قراءة الـ PDF وأسطره ومواقعها ورسم الصفحات (pdf.js) واقتطاع صفحات الدرس (pdf-lib).
- `src/ai.js` — الشرح عبر Claude (`@anthropic-ai/sdk`).
- `src/analyzer.js` — المحلل التلقائي (عناوين، تعاريف، قوانين، أمثلة، تمارين، قص الصور).
- `src/bidi.js` — ترتيب النص العربي/الإنجليزي/المعادلات من مواقع الحروف.
- `src/ocr.js` — تعرّف ضوئي عربي بدون إنترنت (tesseract.js)، ملفاته تُنسخ عبر `scripts/copy-ocr.mjs`.
- `src/summary.js` — اختيار أهم الجمل.
- `src/export.js` — تصدير PDF (jsPDF + html2canvas) و Word (docx).
- `src/storage.js` — الحفظ على الهاتف (Capacitor Filesystem/Share) و IndexedDB.
- `android/` — مشروع Capacitor للأندرويد. `resources/make-icons.cjs` يولّد الأيقونة وشاشة البداية.
- يُبنى الـ APK تلقائياً أيضاً عبر GitHub Actions (`.github/workflows/teacher_planner_apk.yml`).
