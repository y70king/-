# تطبيق الحضور والغياب — ثانوية حي النفط للبنين

تطبيق أندرويد يعمل **بدون إنترنت** لتسجيل الحضور والغياب وتبليغ أولياء الأمور برسائل SMS.

## التنزيل
ملف التثبيت الجاهز: [`release/hay-alnaft-attendance.apk`](release/hay-alnaft-attendance.apk)
(يُبنى أيضاً تلقائياً في GitHub Actions عند كل تعديل).

## المميزات
- **المدرسة:** ثانوية حي النفط للبنين، مع المرحلة والدوام (صباحي/مسائي/مزدوج) والسنة الدراسية والمديرية العامة للتربية.
- **الصفوف والطلاب:** صفوف من الأول الابتدائي إلى السادس الإعدادي، شُعب (أ، ب، ...) ورقم القاعة، بحث سريع، ونسخ طلاب شعبة إلى صف جديد.
- **الاستيراد:** من Excel (xlsx, xls, csv) وWord (docx, doc) أو باللصق، مع أرقام أولياء الأمور أو بدونها.
- **التعداد:** حاضر / غائب / متأخر / مُجاز لكل يوم أو لكل حصة، نقاط نشاط (+1، +2، +5، +10)، سلوك جيد/مشاغب، وملاحظات.
- **تبليغ أولياء الأمور:** فوري عند الغياب عبر SMS (بدون إنترنت) أو واتساب، تبليغات جماعية بقوالب جاهزة، وتقرير فردي نصي أو PDF.
- **دفتر الدرجات:** الأشهر، معدل الفصلين، نصف السنة، السعي السنوي، النهائي، والإعفاء (90) تلقائياً — بدون إعفاء للصفوف الوزارية.
- **ملفات PDF للطباعة (A4):** كشف مادة، الكشف الشامل لكل المواد، تقرير الطالب، شهادة تقديرية للمعفيين، والخطة اليومية.
- **جدول الحصص ومنبه:** يرن قبل الحصة مع زر لأخذ الحضور مباشرة.
- **الخطة التربوية اليومية:** الأهداف المعرفية والوجدانية والمهارية والوسائل وخطوات الدرس والواجب، مع نماذج جاهزة لعشر مواد.
- **الصفوف والشعب:** الصف ← الشُعب (إضافة وحذف) ← صفحة الشعبة: الطلاب، الدرجات، والتقرير.
- **التعداد طالباً طالباً:** اختيار الصف والشعبة ثم عرض كل طالب ببطاقة كبيرة، ومراسلة ولي الأمر فوراً عند الغياب.
- **تقارير لأي فترة:** اليوم، الأسبوع، الشهر، الشهر الماضي، الفصل الأول/الثاني، السنة، أو فترة مخصصة — للصف كاملاً ولكل طالب على حدة (PDF أو واتساب).
- **تنبيه كثرة الغياب:** رسالة تلقائية لولي الأمر عند بلوغ عدد أيام الغياب حداً معيناً.
- **المظهر والشعار:** وضع ليلي، وشعار المدرسة في الشاشة الرئيسية وملفات PDF.
- **الأمان:** قفل التطبيق برمز سري، ورمز قبل الحذف أو الاسترجاع، ونسخ احتياطي واسترجاع.

## البناء
```
./gradlew testDebugUnitTest assembleRelease
```
اختبار `ScreenshotTest` يرسم الشاشات وصفحات ملفات PDF كصور في `app/build/screenshots` و`app/build/pdfs`.
يحتاج JDK 17+ وAndroid SDK 35. الملف الناتج: `app/build/outputs/apk/release/app-release.apk`.
