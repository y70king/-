# إعلان «مطبعة ألوان» — موشن جرافيك

`alwan_ad.mp4`: إعلان عمودي مدته 35 ثانية، بدقة 1080×1920 و60 إطاراً في الثانية، جاهز لـ TikTok وInstagram Reels وFacebook.

| الملف | الوظيفة |
|---|---|
| `anim.js` / `index.html` | محرك الرسوم المتحركة (Canvas)، وكل المشاهد والشخصيات مرسومة بالكود |
| `render.js` | يصدّر الإطارات عن طريق Chromium (Playwright) |
| `audio.py` | يولّد الموسيقى الإلكترونية والمؤثرات الصوتية ويمزجها مع التعليق الصوتي |
| `tts.py`, `vo/` | التعليق الصوتي العراقي (صوت `ar-IQ-BasselNeural`) |
| `build.sh` | يعيد بناء الفيديو كاملاً من المصدر |
