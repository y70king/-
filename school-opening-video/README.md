# افتتاحية مدرسة ثانوية حي النفط للبنين

فيديو افتتاحي سينمائي (موشن جرافيك ثلاثي الأبعاد) مع تعليق صوتي عربي وموسيقى أوركسترالية.

- `opening_1080p.mp4`: النسخة الأصلية، بدقة 1920×1080 و30 إطاراً في الثانية.
- `opening_4k.mp4`: نسخة مكبّرة إلى 3840×2160 من الأصل بدقة 1080p.
- المدة: 77 ثانية تقريباً، وفيها النص الكامل للتعليق الصوتي دون تسريع في الإلقاء.

## المشاهد

| الزمن | المشهد |
|---|---|
| 0:00 | بداية الهيبة: خيوط ضوئية ذهبية تتجمع في أشكال هندسية، وضربة صوتية عميقة |
| 0:12 | انبثاق المعرفة: كتب وأقلام ونجوم وذرّة وقبعة تخرّج تحلّق الكاميرا بينها نحو هالة ذهبية |
| 0:23 | صرح المستقبل: مبنى مدرسي معماري عام (ليس المبنى الحقيقي) والكاميرا تتقدم من زاوية منخفضة نحو المدخل |
| 0:35 | الإعلان الرسمي: العبور عبر بوابات ضوئية، ثم «بكل فخرٍ واعتزاز» ثم الكشف عن اسم المدرسة |
| 0:47 | رسالة المدرسة: كتب ونجوم تدور حول الاسم، وتظهر «العلم · التميّز · المستقبل» ثم تندمج |
| 1:04 | الختام الملكي: هالة ذهبية، والاسم بحروف ذهبية مجسّمة يمرّ عليها لمعان من اليمين إلى اليسار، وضربة ختامية |

## طريقة الإنتاج (`src/`)

- `tts.py`: يولّد التعليق الصوتي بصوت عربي رجولي فصيح بتقنية الأصوات العصبونية (Microsoft Edge `ar-SA-HamedNeural`).
- `index.html`: المشهد ثلاثي الأبعاد (three.js مع Bloom وانعكاسات)، والنصوص العربية بخطوط Amiri وAref Ruqaa وReem Kufi.
- `render.js`: يصيّر المشهد إطاراً إطاراً عبر Playwright/Chromium.
- `music.py`: يولّد الموسيقى الأوركسترالية برمجياً (وتريات، نحاسيات، كورال، طبول تيمباني، ضربات، مؤثرات تصاعدية، صدى)، ويمزجها مع التعليق ويخفّضها تلقائياً أثناء الكلام.

```bash
python3 tts.py                                   # vo/s1..s6.mp3 ثم تُقصّ وتُحوَّل إلى wav
python3 -m http.server 8765 &                     # من داخل src/ (يتطلب مكتبة three@0.160 في lib/)
node render.js frames 30 0 2310                   # الإطارات
python3 music.py                                  # mix.wav
ffmpeg -framerate 30 -i frames/f%05d.jpg -i mix.wav -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac -b:a 256k opening_1080p.mp4
```

لاستبدال مشهد المبنى العام بصورة المدرسة الحقيقية، يمكن إضافة الصورة كخامة في المشهد الثالث داخل `index.html`.
