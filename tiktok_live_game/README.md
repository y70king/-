# ⚔️ ساحة البث — لعبة تفاعلية لبث تيك توك من التلفون

المشاهدين يدخلون الساحة بأسمائهم لما يدزون لايكات أو هدايا. المقاتلين يتصادمون، وآخر واحد يبقى يفوز.
**صوت عربي** يعلّق على كل شي يصير (مثل "أرسل علي وردة، وأخذ درع حماية" أو "دخل حسين للعبة")، والتعليق نفسه يظهر **مكتوب** على الشاشة.

## شلون تشتغل
| بالبث | بالعبة | التعليق |
|---|---|---|
| ❤️ كل **20 لايك** | الشخص اللي كمّل الـ20 يدخل الساحة. إذا هو موجود يرتفع مستواه | "دخل فلان للعبة" |
| 💬 تعليق `!join` أو `دخول` أو `انضم` | يدخل الساحة | "دخل فلان للعبة" |
| 🌹 هدية من 1 ماسة | 🛡️ درع حماية | "أرسل فلان وردة، وأخذ درع حماية" |
| 🎁 هدية من 10 ماسات | 🦍 يصير عملاق | "… وصار عملاق" |
| 💣 هدية من 100 ماسة | قنبلة تضرب كل اللي يمه | "… وفجّر قنبلة" |
| 👑 هدية من 500 ماسة | يصير الملك | "… وصار الملك" |
| ➕ متابعة / ↗ مشاركة | يدخل الساحة | "فلان تابع البث" |
| نهاية الجولة | — | "الفائز هو فلان" |

تكدر تغيّر كل الأرقام من ملف `config.json`.

## 📱 التشغيل من التلفون

اللعبة بيها جزئين:
1. **السيرفر**: يقرا اللايكات والهدايا من بثك.
2. **صفحة اللعبة**: تفتحها بمتصفح التلفون.

### الخطوة 1: ارفع السيرفر على الإنترنت (مرة وحدة بس، ومجاناً)
1. ادخل على [render.com](https://render.com) من التلفون وسجّل دخول بحساب GitHub.
2. اضغط **New ← Blueprint** واختار هذا المستودع. راح يقرا ملف `render.yaml` ويجهز كلشي وحده.
   - أو اضغط **New ← Web Service** واختار المستودع، وبعدين خلي:
     **Root Directory** = `tiktok_live_game`،
     **Build Command** = `npm install`،
     **Start Command** = `npm start`،
     **Instance Type** = Free.
   - إذا الكود بعده بفرع غير `main`، اختار الفرع من خانة **Branch**.
3. انتظر دقيقتين. راح يعطيك رابط مثل `https://tiktok-live-game-xxxx.onrender.com`. **احفظه.**

> النسخة المجانية تنام إذا محد استخدمها 15 دقيقة. فافتح الرابط قبل البث بدقيقة حتى تصحى.

### الخطوة 2: البث
1. افتح تيك توك واختار بث **شاشة الموبايل** (بث الألعاب / Mobile Gaming).
   - إذا الخيار مو موجود عندك، معناها حسابك بعده ما عنده هالخاصية.
2. افتح رابط Render بمتصفح Chrome أو Safari.
3. اكتب يوزرك واضغط **▶ ابدأ**.
   - هاي الضغطة ضرورية حتى التلفون يسمح للصوت يشتغل.
4. اللعبة تملي الشاشة والصوت يبدي يعلّق.
5. حتى ترجع للإعدادات، اضغط ⚙️ اللي بالزاوية، أو اضغط مرتين على عنوان اللعبة فوك.

### نصائح للتلفون
- **الصوت**: لازم مستوى صوت التلفون (الميديا) يكون عالي. وبالإعدادات اضغط "🔈 جرّب الصوت".
- إذا الصوت يطلع بلهجة غريبة أو ما يطلع: Android ← الإعدادات ← تحويل النص إلى كلام ← نزّل اللغة العربية. iPhone ← الإعدادات ← تسهيلات الاستخدام ← المحتوى المنطوق ← الأصوات ← العربية.
- حتى صوت التعليق يوصل للمشاهدين، لازم بث الشاشة ينقل صوت التلفون. على Android 10 وأحدث وعلى iPhone هذا يصير عادةً. جرّبه أول مرة وخلي واحد يتأكدلك.
- الشاشة تبقى شغالة وحدها أثناء اللعب.

### بديل لأجهزة Android (بدون Render)
تكدر تشغل السيرفر على نفس التلفون باستخدام تطبيق [Termux](https://f-droid.org/packages/com.termux/):
```
pkg install nodejs git
git clone <رابط المستودع>
cd <اسم المجلد>/tiktok_live_game
npm install
npm start
```
بعدها افتح `http://localhost:3000` بالمتصفح. لازم Termux يبقى شغال بالخلفية.

## 🧪 التجربة قبل البث
- من شاشة البداية اضغط **🧪 تجربة بدون بث**، فتطلع مشاهدين وهميين يدزون لايكات وهدايا.
- فعّل **أزرار التجربة** من الإعدادات حتى تجرب كل هدية بنفسك.

## 💻 من الكمبيوتر (اختياري)
اكتب `npm install` وبعدها `npm start`. بعدين بـ OBS أو TikTok LIVE Studio ضيف Browser Source على الرابط
`http://localhost:3000/?user=يوزرك` بحجم 1080×1920. إذا تريد خلفية شفافة ضيف `&transparent=1`.

## ⚠️ ملاحظات
- الربط وية تيك توك يعتمد على مكتبة **غير رسمية** (tiktok-live-connector). إذا تيك توك غيّر نظامه، ممكن توكف لحد ما تتحدث المكتبة.
- بالبثوث الكبيرة تيك توك ما يرسل كل اللايكات، فالعداد ممكن يتأخر.
- إذا تيك توك رفض الاتصال من سيرفر Render، جرّب طريقة Termux أو الكمبيوتر.
- إذا طلع خطأ rate limit، سوّ حساب على eulerstream.com وحط المفتاح بـ Render ← Environment كمتغير باسم `EULER_API_KEY`.
- أي واحد عنده رابط Render يكدر يفتح اللعبة، فلا تنشره.
