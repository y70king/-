# إعلان «تيربو للتوصيل السريع» — Motion Graphics (9:16)

- `turbo_delivery_4k.mp4` — 2160×3840، 30fps، 89.5 ثانية، تعليق صوتي عربي فصيح طوال الإعلان، AAC ستيريو (−14 LUFS).
- `turbo_delivery_1080p.mp4` — 1080×1920.

المشاهد: TURBO والانطلاقة ← الطلب على الهاتف ← خريطة بيجي ثلاثية الأبعاد ومناطقها (الحجاج، المزرعة، الـ600، المصافي، ساحات المصافي، الصينية)
← بيجي ↔ تكريت ← خط السرعة (سرعة • دقة • موثوقية) ← الطلبات إلى صندوق الدراجة ← الانتشار ووجهتك ← هوية تيربو ← للطلب والاستفسار ← الخاتمة.

- المركبة دراجة توصيل (سكوتر) لأن أغلب الطلبات تُنجز بالدراجة.
- الشعار مُعاد رسمه بالكانفاس اعتمادًا على صورة الشعار (`brand/logo-reference.jpg`)؛ يمكن استبداله بملف الشعار الأصلي إن توفر.
- أرقام الطلب (`PHONES` في `ad.html`) تظهر علامةً مائية أعلى الفيديو، وفي مشهد التواصل، وفي البطاقة الختامية.
- خريطة المناطق تخطيطية (ليست دقيقة جغرافيًا).

المصادر: `ad.html` (المشاهد)، `render.mjs` (تصيير الإطارات)، `audio.py` (موسيقى منخفضة ومؤثرات ومكساج)، `vo/` (التعليق الصوتي وتوقيت الكلمات).
