# تطبيق الحضور والغياب — ثانوية حي النفط للبنين

تطبيق أندرويد يعمل **بدون إنترنت** لتسجيل الحضور والغياب وتبليغ أولياء الأمور برسائل SMS.

## التنزيل
ملف التثبيت الجاهز: [`release/hay-alnaft-attendance.apk`](release/hay-alnaft-attendance.apk)
(يُبنى أيضاً تلقائياً في GitHub Actions عند كل تعديل).

## المميزات
- تسجيل الحضور بنقرة: حاضر / غائب / متأخر / مُجاز، وزر «الباقون حاضرون».
- تبليغ فوري لولي الأمر برسالة SMS من شريحة الهاتف عند تسجيل الغياب (يمكن إيقافه).
- استيراد الطلاب من Excel (xlsx) وWord (docx) وCSV أو بالنسخ واللصق، مع التعرف على رقم ولي الأمر.
- تبليغات لطالب محدد أو لصف أو لجميع الطلاب، مع قوالب جاهزة وسجل للرسائل.
- أكثر من مدرسة، وبيانات كل مدرسة منفصلة.
- تقارير يومية وإحصائيات لكل طالب وتصديرها لملف Excel (CSV).
- نسخ احتياطي واسترجاع لكل البيانات.

## البناء
```
./gradlew testDebugUnitTest assembleRelease
```
يحتاج JDK 17+ وAndroid SDK 35. الملف الناتج: `app/build/outputs/apk/release/app-release.apk`.
